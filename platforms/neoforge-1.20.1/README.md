# Ban Dream - NeoForge 1.20.1

Standalone development environment for Minecraft 1.20.1 NeoForge.

- Gradle: 8.14.2
- Java: 17
- ModDevGradle Legacy: 2.0.148
- NeoForge-compatible legacy API: 47.1.x
- Mod ID: `bandream`
- Display name: `Ban Dream`

## Tasks

```text
gradlew.bat build
gradlew.bat runClient
gradlew.bat runServer
```

The 1.20.1 NeoForge line uses the legacy Forge-compatible API. This project uses
NeoForged's official legacy MDK and targets NeoForge 1.20.1 metadata.
