# Ban Dream 1.4.0

- Added block bans with global scope; entity bans retain dimension scope.
- Added `/bbban ban block`.
- Ban Stick left-click now selects blocks for confirmation.
- Block bans now replace the original block with a `bakaban` marker and preserve the original state and BlockEntity by UUID.
- Banned items are replaced by UUID-backed `999ban` markers; banned block markers use the `bakaban` model.
- Item snapshots preserve the original ItemStack, count, item ID and NBT through bans, restarts and unbans.
- Banned blocks allow destruction and placement while disabling right-click use, block/entity ticks, neighbor updates, random ticks and fluid ticks.
- Block-entity tick suppression uses the chunk ticker wrapper to coexist with other mods that redirect `Level.tickBlockEntities`.
- Dimension scope is now restricted to entities; old non-entity dimension rules normalize to global.
- Ban Stick actions are excluded from the block-use guard so right-click unban prompts can open correctly.
- Banned blocks reject hopper and Forge-capability item input/output.
- Banned containers and pipes no longer exchange items after rules change.
- `/bbban list block` now opens the same paginated, read-only list interface as items.
- Block list entries show scope in their tooltips.
- `/bbban list item book` and `/bbban list block book` now generate written books.
- Shared list grouping and display text were consolidated.
- Ban Stick clicks now open block, mob and barrel option panels.
- Right-clicking a block or mob opens a bottom-right global unban confirmation.
- Sneak right-clicking a barrel globally unbans all contained item IDs immediately.
- Item and block list entries now open a management panel for bans or unbans.
- Added snapshot audit commands for item/block listing, inspection, deletion and orphan candidates.
- Fixed `LevelChunkTickerMixin` to inject into `LevelChunk.updateBlockEntityTicker` instead of shadowing a synthetic wrapper field.
- Restored item entities now lose marker-only unlimited lifetime and invulnerability.
- Block entity snapshots strip old `id`, `x`, `y`, and `z` metadata before loading at a new position.
- Block and item marker copies without a backing snapshot are labeled as missing instead of silently becoming empty markers.
- Block scanner budgets are shared globally and include a two-millisecond per-tick time cap.
- Block scanner replacements use client-only update flags to avoid full neighbor-update amplification.
- Rule loading now rejects malformed or duplicate rules and keeps the previous valid index.
- Added optional Curios support for redirecting and restoring banned equipped items.
- Restricted list entry management to left-click and closed the old list container first.
- Preserved JEI visibility when changing an item ban mode.
- Guarded client choice packets during disconnects and deduplicated entity right-click events.
- Refreshed Curios stacks after item redirection or enchantment cleanup.
- Added rule-type fast paths for entities, structures, dimensions, effects and enchantments.
- Removed periodic player inventory scanning; item redirects use inventory insertion and set hooks.
- The legacy coordinate-based block snapshot path was replaced by UUID-based snapshots.
- Failed block-entity restoration keeps the marker and snapshot intact.
- Added Curios change-event handling without a hard dependency.
- Added early exits for block and structure events when no matching rule type exists.
- Corrected hopper tick checks to inspect the actual output side.
- Cached item, block, entity and dimension IDs for hot-path rule lookups.
- Added the `bakaban` display item with a six-face texture.
- Block bans now store complete snapshots by UUID and redirect to `bakaban`.
- `bakaban` follows its current position when broken and placed again.
- Config load failures abort startup with a path-qualified exception instead of being silently ignored.
- Renamed all user-facing mod titles to Ban Dream.
- Removed development logging and explanatory comments from packaged sources; config-load failures are surfaced through startup exceptions.
- Moved architecture and build notes into the workspace `docs` directory.
- Added Forge 1.12.2, Cleanroom 1.12.2, NeoForge 1.20.1, and NeoForge 1.21.1 workspaces.
